# 人工身份修正 SOP

最终 fish_1 / fish_2 / fish_3 不是 ByteTrack 原始 ID。

复核流程：

1. 生成 fish_1 / fish_2 / fish_3 回投影视频；
2. 对照 TOP 与 LEFT 同步视角；
3. 标记身份交换区间和不稳定过渡帧；
4. 使用状态机规则修正持续性标签错配；
5. 将不确定点或局部错误定位点设为无效；
6. 重新插值和平滑最终轨迹；
7. 再次生成 QC 图和行为指标。
