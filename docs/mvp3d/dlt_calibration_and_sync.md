# DLT 标定与 TOP/LEFT 同步记录

DLT 标定使用 8 个鱼缸结构点。

标定质量：

- TOP 平均重投影误差：3.12 px；
- TOP 中位重投影误差：3.29 px；
- TOP 最大重投影误差：4.53 px；
- LEFT 平均重投影误差：5.12 px；
- LEFT 中位重投影误差：5.51 px；
- LEFT 最大重投影误差：7.83 px。

时间同步扫描结果：

- LEFT_sample = TOP_sample + 460；
- 30 Hz 下 offset = 15.333 s；
- 快速扫描中位重投影误差：2.83 px；
- 快速扫描平均重投影误差：4.82 px。

该结果说明，初始三维重建误差过高的主要原因是 TOP/LEFT 时间不同步，而不是 DLT 标定完全失败。
