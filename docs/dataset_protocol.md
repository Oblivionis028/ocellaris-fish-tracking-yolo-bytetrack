# 数据集构建记录

当前数据集通过多轮抽帧、YOLO 预标注和 CVAT 人工修正构建。

累计数据规模：

- 训练图像：1128 张；
- 验证图像：233 张；
- 总图像：1361 张；
- 训练标注框：4432 个；
- 验证标注框：939 个。

主要数据批次包括：

- 早期基础数据；
- top2m；
- top5m300；
- V5 train200 / val100；
- V6 train300 / val100。

V6 修正阶段发现的主要问题：

- 预标注框普遍略偏大；
- 约 10 张图存在单鱼重复标注；
- 约 5 张简单场景中存在真实鱼漏检。

这些问题为后续 hard sample 筛选和标注 SOP 完善提供了依据。
